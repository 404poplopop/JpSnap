# Third-party data

- `accents.txt`: Japanese pitch accent data from Kanjium (https://github.com/mifunetoshiro/kanjium),
  `data/source_files/raw/accents.txt`, licensed CC BY-SA 4.0. Unmodified.
- Voice: edge-tts (https://github.com/rany2/edge-tts, LGPL-3.0, installed with pip, not vendored) using the
  Microsoft Edge read-aloud service. It is not an official API and may stop working.
